# Memo — веб-приложение на Python

Учебный проект по домашнему заданию: вёрстка страниц на Bootstrap 5 и простое
веб-приложение на стандартной библиотеке Python, которое отдаёт готовые
HTML-страницы и принимает POST-запрос формы обратной связи.

## Цель работы

Закрепить основы работы веб-приложения «под капотом»: научиться отдавать
HTML-страницы с корректным заголовком `Content-Type`, читать файлы через
контекстный менеджер `with open(...)`, обрабатывать GET- и POST-запросы без
использования фреймворков.

## Что реализовано

- Свёрстаны страницы по макетам: «Главная», «Каталог», «Категория 1»,
  «Контакты».
- Общие блоки страниц: боковая панель (`header` с логотипом и меню),
  основное содержимое (`main`) и подвал (`footer`) с выпадающим меню.
- Bootstrap 5 и Bootstrap Icons подключены с удалённого CDN.
- Сервер на `http.server` отдаёт HTML-страницы с `Content-Type: text/html`.
- HTML-файлы читаются через контекстный менеджер `with open(...)`.
- Реализована страница 404, а также страница 500 на случай внутренней ошибки.
- Форма на странице «Контакты» отправляет POST-запрос; полученные данные
  выводятся в консоль, после отправки на странице показывается уведомление.

## Запуск

Требуется Python 3.10 или новее. Внешние зависимости не нужны.

```bash
python server.py
```

После запуска откройте <http://127.0.0.1:8000/>.

Можно указать другой хост и порт:

```bash
python server.py --host 0.0.0.0 --port 8080
```

## Маршруты

| Метод | URL | Результат |
|-------|-----|-----------|
| GET | `/` или `/index` | Страница «Главная» |
| GET | `/catalog` | Страница «Каталог» |
| GET | `/category` | Страница «Категория 1» |
| GET | `/contacts` | Страница «Контакты» |
| POST | `/contacts` | Приём данных формы и повторный показ страницы «Контакты» |
| GET | любой другой URL | Страница 404 |

Например, чтобы увидеть страницу 404, откройте
<http://127.0.0.1:8000/orders> или любой несуществующий адрес.

## Проверка POST-запроса

Заполните форму на странице «Контакты» и нажмите «Отправить». В консоли
сервера появятся введённые данные:

```
POST /contacts
  name: Иван
  email: ivan@example.com
  message: Проверка отправки формы
```

Этот же запрос можно выполнить из консоли:

```bash
curl -X POST http://127.0.0.1:8000/contacts \
  -d "name=Иван&email=ivan@example.com&message=Тест"
```
